Host Krillion on GitHub Pages

Krillion is built as a zero-backend single HTML file using WebRTC peer-to-peer room codes, meaning multiplayer works directly on GitHub Pages for free!

  1. Create a new public repository on GitHub (e.g., krillion-game).
  2. Upload this single file renamed as index.html.
  3. Open Settings → Pages in your repository.
  4. Under Build and deployment, select Deploy from a branch → main / /(root) and click Save.
  5. Share your username.github.io/krillion-game link with friends!
